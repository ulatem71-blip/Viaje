# Viaje Rentable 1.5 — diagnóstico

Proyecto Android Kotlin. Esta versión es solo de diagnóstico: registra texto accesible visible de Uber Driver cuando el servicio tiene permiso. No pulsa controles ni acepta viajes automáticamente.

## Abrir
1. Descarga y extrae el ZIP.
2. Abre la carpeta `ViajeRentable-v1.5` desde Android Studio.
3. Espera a que termine Gradle Sync.
4. Ejecuta en un dispositivo Android de prueba.
5. En la app, abre ajustes de accesibilidad y activa Viaje Rentable.
6. Vuelve a la app y pulsa “Actualizar registro”.

## Compilación
El workflow de GitHub Actions intenta generar el APK y ejecutar pruebas. El proyecto no se ha compilado ni validado en un dispositivo real en esta entrega. Para uso con Uber, verifica las condiciones aplicables y mantén desactivada cualquier aceptación automática.
